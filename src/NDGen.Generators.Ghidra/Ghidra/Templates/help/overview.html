ND-100 Processor Support

This extension provides comprehensive support for the Norsk Data ND-100 16-bit minicomputer architecture in Ghidra.

Features

  • Complete Instruction Set - Support for all 153 ND-100 instructions
  • BPUN File Loader - Native support for Bootable Punched Tape format
  • Architecture Support - 16-bit big-endian processor with 64KB address space
  • Symbol Recognition - Automatic entry point and symbol detection

Architecture Overview

The ND-100 is a 16-bit big-endian minicomputer with the following characteristics:

  • Word Size: 16 bits
  • Address Space: 64KB (0x0000 - 0xFFFF)
  • Byte Order: Big-endian (MSB first)
  • Registers: A, B, D, L, P, T, X, STS

Getting Started

  1. Import a BPUN file or ND-100 binary
  2. Select the ND-100:BE:16:default language if prompted
  3. Run Ghidra's auto-analysis
  4. Refer to the Instruction Reference for detailed instruction information
